# EchoPane · 随幕

让屏幕文字和正在播放的语音，变成可阅读的双语字幕。

EchoPane 是一款面向 PC 的实时翻译工具，计划支持屏幕文字识别、系统音频转写和双语悬浮字幕，帮助理解外语视频、直播及其他屏幕内容。

> 项目处于早期开发阶段，目前尚无可下载安装的版本。以下功能为产品目标，实际支持范围以发布版本为准。

## 计划功能

- **屏幕翻译**：持续识别框选区域或整块显示器中的文字，翻译为选定的目标语言。
- **语音字幕**：将系统正在播放的语音转写为文字，并提供翻译。
- **双语对照**：在可移动、可调整大小的悬浮窗中展示原文与译文，无需语音播报。
- **语言设置**：自动判断源语言，也支持手动指定；首批重点验证英语、日语到简体中文。
- **会话记录**：回看当前会话中的字幕，支持主动复制或导出。

首版计划通过模式切换使用屏幕翻译或语音字幕；后续支持两种模式同时运行，并按来源分别展示。

## 平台

首个目标平台为 **Windows 11 x64**。macOS 和 Linux 桌面端作为后续扩展方向，移动端纳入长期规划。

## 数据与隐私

默认方案是在本机识别截图和音频，仅将识别后的文字发送给用户选择的翻译服务。使用在线翻译时，文本仍会传输到该服务。

计划由用户在图形界面配置自己的翻译服务 API Key。字幕历史默认仅保留在当前会话中，用户可以主动导出。
