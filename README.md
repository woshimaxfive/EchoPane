# EchoPane · 随幕

让画面文字在原位置翻译，让正在播放的语音变成双语字幕。

EchoPane 是一款面向 PC 的实时翻译工具，目标是帮助理解外语视频、直播及其他屏幕内容。

> 项目处于早期开发阶段。当前提供原位翻译和音频翻译两种模式：画面文字在原位置显示译文，系统播放语音使用独立字幕窗。英语、日语短录音已通过真实云端调用，连续视频的翻译质量与延迟仍需验证；目前没有正式发行的安装包。

## 当前功能

- **原位翻译**：选择显示器、整屏或框选区域；本地识别文字，联网翻译后在原文下方显示或原位置覆盖。
- 原位页提供范围预览和运行状态，屏幕文字不会进入独立字幕窗，也不另设双语文字查看面板。
- **音频翻译**：采集所选播放设备的语音，可选择本地识别后联网翻译，或百炼实时语音翻译。
- 英语本地实时识别连续显示临时原文，稳定片段联网翻译；多语种本地识别保留英语、日语和自动判断。
- 音频专用悬浮字幕窗支持双语、原文或译文，按窗口宽度换行、滚动，完整译文保留阅读时间。
- 字幕窗支持移动、调整大小、置顶、透明度、鼠标穿透与远程可见性；切回原位翻译时关闭音频字幕窗。
- DeepSeek 官方、阿里云百炼及自定义兼容服务，配置源语言、目标语言和 API Key。
- 本地模型按需下载、校验和缓存；截图与本地模式音频不上传，文本翻译只发送文字。
- 最小化到托盘后继续运行，提供恢复、停止、隐藏译文及退出操作。
- 本次运行记录可回看、复制，并主动导出 TXT 或 JSON；只记录最终音频结果。

当前捕获画面只在本机内存中处理，不上传或自动保存截图。

## 使用原位翻译

1. 选择 **原位翻译**，首次使用下载约 **21.5 MB** 的文字识别模型。
2. 在 **翻译服务** 中保存服务地址、模型、Key 和目标语言。
3. 选择显示器，框选关注的文字区域，或选择 **整块屏幕**。按 Esc 取消框选。
4. 在 **显示设置** 中选择 **译文显示在原文下方** 或 **原位置替换原文**。
5. 点击 **开始原位翻译**。该操作同时开始识别、翻译和原位显示；点击 **停止原位翻译** 结束并清除画面译文。

主窗口仅显示范围预览和状态；识别文字及译文不在这里另列，也不会进入音频字幕窗。请把主窗口移出识别区域，或最小化到托盘，避免再次识别预览画面。原位结果可在字幕记录中回看。

原位显示仍为实验功能。当前重点验证英语、日语横排文字，小字、运动背景和字体会影响识别。覆盖模式采用采样背景色，复杂背景可能留下色块；下方模式位置不足时会跳过该块，长译文可能缩小或裁剪。

译文窗口允许鼠标穿透。可通过托盘或 Ctrl + Alt + T（快捷键可用时）隐藏原位译文，停止后重新开始会恢复显示。默认允许远程桌面和录屏显示；识别取样时短暂隐藏译文，部分场景可能闪烁。关闭远程兼容可减少闪烁，但远程软件可能看不到译文。真实连续视频、多屏不同缩放、独占全屏及具体 UU 场景尚待验证。

## 使用音频翻译

英语视频可在音频翻译中选择 **本地实时识别 · 英语**，首次下载约 **73.4 MB** 的模型后点击 **开始**。原文在本机连续更新，临时文字可能修正；不开启翻译时无需 Key，完整模型缓存可离线使用。开启翻译后只发送稳定的文字片段，关闭翻译不会停止原文识别。翻译网络失败时保留原文，可手动重试。只有识别完成的片段加入记录，随后收到的最终译文会补到对应记录。

此模式目前固定识别英语。需要日语或自动语言判断时，选择 **本地语音识别**，沿用下面的多语种方式。模型精度受口音、背景噪声及混合声音影响，实时出字不代表识别准确；推理跟不上或设备变化时会提示重新开始。

1. 在顶部切换为 **音频翻译**，首次使用点击 **下载模型 · 148.8 MB**。完整缓存后，语音识别可离线使用。
2. 选择 **跟随系统默认播放设备**，或指定一个耳机/扬声器。识别语言可选自动、英语或日语；更换设备或语言会停止当前识别，需要重新点击开始。
3. 点击 **开始**，播放视频或会议声音。输入音量条显示采集状态，识别原文按句段更新；它采集所选设备上的混合声音，麦克风关闭。
4. 按需开启 **翻译** 和 **音频字幕**。没有 Key 也可查看原文。切换模式、停止或设备重新路由后会清空旧字幕，过时译文不会带到新会话。

语音检测在停顿约 640 ms 后提交，连续语音最多约 6 秒一段，随后仍需等待本地推理。当前默认 Whisper base 使用 CPU，延迟与准确率取决于电脑、声音和语言；自动语言检测可能出错，背景音乐或多人同时说话也会干扰识别。输入缓冲有上限，识别跟不上时会提示并跳过部分音频。当前只监听一个播放端点，独占音频、受保护内容及部分设备可能无法捕获。默认设备切换与热插拔仍需更多实际设备验证。

### 使用云端实时语音翻译

1. 在 **翻译服务** 中保存百炼北京预设和自己的 Key，选择目标语言。
2. 在 **音频翻译** 中将 **本地语音识别** 切换为 **百炼实时翻译 · 云端**，选择播放设备后点击 **开始**。连接完成后开始上传该设备的混合声音，无需下载本地语音模型。
3. 原文和译文随语音更新，临时字幕可能修正；仅确认完成的双语结果进入记录。点击 **停止** 后停止采集，并等待服务端完成最后一段，等待结果最多 10 秒。连接失败、音频丢失或设备改变时停止上传并提示重新开始，不会自动重连。

消息到达顺序不一致时，会按服务端编号暂存并配对。单段字幕无法配对时跳过该段并继续监听，连续三段配对失败才停止。出现警告或错误时可点击 **复制诊断**；诊断仅包含事件类型、匿名编号和时间，不包含字幕正文、录音或 Key。

实时语音使用 [`qwen3.5-livetranslate-flash-realtime`](https://help.aliyun.com/zh/model-studio/qwen3-5-livetranslate-flash-realtime)，与屏幕和本地识别后的 DeepSeek 文本翻译分别调用，共用已保存的北京 Key。支持北京公共域名及北京工作空间地址；目前不支持指定繁体中文输出。选择其他服务或地域时需先改回北京配置。重启后默认使用本地识别，不自动上传声音。

纯文字模式不会播放合成语音。声音会发送至阿里云并可能按用量计费，网络和模型服务会影响延迟；临时译文出现得早并不代表整句已经完成。修改翻译配置或关闭翻译会停止当前实时会话；重新开始后使用新配置。

## 使用翻译

1. 打开 **翻译服务**，选择 DeepSeek 官方或阿里云百炼预设，也可填写自定义服务地址和模型名称。
2. 填写自己的 API Key，选择源语言与目标语言后保存。Key 保存在当前用户的 Windows 凭据管理器中；普通配置文件不包含 Key。更换服务主机时，旧 Key 不会自动带到新服务。
3. 原位翻译通过 **开始原位翻译** 启动；音频翻译可在开始识别后手动开启 **翻译**。没有 Key 时，可以使用本地音频原文识别；本机无鉴权模型服务允许留空 Key。
4. 翻译失败时检查地址、模型、Key 或余额，再点击 **重试翻译**。重启应用后翻译默认关闭。

自定义地址可以填写基础地址（例如 `https://example.com/v1`），也可以填写完整 `/chat/completions` 地址。远程服务必须使用 HTTPS；HTTP 仅允许本机回环地址。高级设置可关闭服务不支持的 JSON 模式或思考参数。协议兼容性取决于具体服务，模型仍需按约定返回完整 JSON 段落；当前未逐一验证第三方服务。

DeepSeek 预设为 `https://api.deepseek.com`、`deepseek-flash`，关闭思考并请求 JSON 输出，依据 [官方接口文档](https://api-docs.deepseek.com/en/)。实际可用模型以服务方为准。在线调用可能产生费用；应用不会在失败后自动重试。“测试连接”只发送一句固定测试文本，也可能产生服务费用。

阿里云百炼预设使用北京地域地址 `https://dashscope.aliyuncs.com/compatible-mode/v1` 和 `deepseek-v4-flash`，请求 JSON 输出并通过 `enable_thinking: false` 关闭思考。可把地址改为控制台提供的同地域业务空间专属地址，API Key 的地域必须与地址一致。百炼的模型名称与 DeepSeek 官方不同，实际可用型号以控制台为准。依据 [百炼 DeepSeek 文档](https://help.aliyun.com/zh/model-studio/deepseek-api) 与 [OpenAI 兼容接入文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。

## 使用音频字幕

1. 在 **音频翻译** 中打开 **音频字幕**，开启 **显示音频字幕窗口**。字幕窗口独立置顶，开始识别后显示内容；没有 Key 时可使用原文或双语模式查看原文。
2. 拖动字幕窗口移动位置，从边缘调整大小；右上角关闭按钮只隐藏字幕，不停止捕获。最小化主窗口后，字幕继续显示。
3. 选择显示内容、字号、背景不透明度和最多行数，点击 **保存样式**。双语模式在译文未就绪时显示原文；只看译文模式会等待对应译文。音频字幕按可用空间换行、滚动。
4. 开启 **鼠标穿透** 后，可操作下方的视频。通过主窗口设置中的 **恢复字幕操作并重置位置**，或托盘菜单的 **恢复字幕操作** 退出穿透，并将窗口放回当前所选显示器。若快捷键注册成功，也可按 **Ctrl + Alt + S** 退出穿透；快捷键冲突时仍可使用主窗口和托盘。

音频悬浮字幕按窗口宽度和字号换行、逐行滚动，长段不再以省略号截断。空间足够时同时保留上一段和当前段，临时原译文在对应段落中修正；完整译文出现后保留阅读时间，文字量较多时适当延长。原文和译文分别换行，仍对应同一个语音段，不保证每一显示行逐句对齐。小窗口优先显示译文；快速连续讲话或长段积压时会推进较旧内容，以限制显示延迟，完整确认结果可在字幕记录中回看。停止或切换会话会立即清空，重新打开字幕窗从当前语音开始显示。

如需在远程桌面或录屏中看到悬浮字幕，在 **音频字幕** 中开启 **允许远程桌面和录屏显示字幕**，再点击 **保存样式**。这个开关独立于鼠标穿透；当前保留原有远程兼容设置，开启后允许远程显示音频字幕。独立字幕窗只接收音频内容。具体远程软件的显示效果仍需实际验证。

样式与远程兼容设置保存在 `%LOCALAPPDATA%/EchoPane/subtitles.json`，不包含字幕内容。重启时字幕窗口默认隐藏，鼠标穿透默认关闭。当前已验证 Windows 本机夹具、捕获排除和窗口生命周期；独占全屏、不同 DPI 多屏切换、长视频与连续云端翻译尚待实测。

## 使用字幕记录

点击顶部的 **字幕记录**（时钟图标），可回看本次打开应用期间的原文与对应译文。界面按最新在前排列，显示收到时间和屏幕/音频来源。停止识别或切换模式后记录仍然保留；没有开启翻译或翻译失败时，保留原文。

使用 **复制这一条** 或 **复制全部** 复制内容；选择 TXT 或 JSON 后点击 **导出**，在系统“另存为”窗口选择位置。导出的是点击时已有记录的快照，按收到先后排列，采用 UTF-8 编码。时间为字幕收到的时间，导出使用 UTC，不是视频时间轴；当前不生成 SRT。

记录只保留在内存中，不自动写文件，退出应用后清空；也可主动点击 **清空**。最多保留 1000 条、合计约 100 万字符，超过上限会移除较早记录并提示数量。应用记录识别器提交的字幕，不能保证每句视频台词都完整保留。

## 计划功能

- **字幕稳定**：改善动态背景、小字和识别抖动，验证真实视频的翻译质量与延迟。
- **语音识别优化**：验证真实视频、长时间运行和设备切换，增加可选模型与硬件加速。
- **语言扩展**：按 OCR 模型和翻译服务能力验证更多语言；语言设置列表不代表对应 OCR 语言均已验证。
- **长期记录**：按需保存、搜索历史字幕。

当前通过模式切换使用原位翻译或音频翻译；后续支持两种模式同时运行，画面文字原位显示，语音使用独立字幕窗。

## 平台

当前开发与验证平台为 **Windows 11 x64**。macOS 和 Linux 桌面端作为后续扩展方向，移动端纳入长期规划。

## 从源码运行

需要 Flutter 3.47.6（Dart 3.13.5）及 Visual Studio 的“使用 C++ 的桌面开发”工具和 Windows SDK 10.0.26100 或更新版本。Windows 需开启开发者模式，以支持 Flutter 插件的符号链接。

首次 Windows 构建会下载并校验官方 ONNX Runtime 1.30.0 与 OpenCV 4.13.0 开发包，下载量约 277 MB。默认缓存在构建目录的 `ocr-deps/` 中；可通过环境变量 `ECHOPANE_OCR_DEPS` 指定持久缓存目录。另外会下载并校验约 14.4 MB 的 whisper.cpp 与 miniaudio 源码，缓存可通过 `ECHOPANE_AUDIO_DEPS` 指定。CPU 后端随包附带并根据处理器能力选择，不要求 CUDA。构建依赖与应用内下载的识别模型相互独立。

```powershell
flutter pub get
flutter run -d windows
```

构建 Windows 版本：

```powershell
flutter build windows --release
```

输出位于 `build/windows/x64/runner/Release/`。运行 `echopane.exe` 时，需要保留同目录下的 DLL、`data/` 和 `licenses/` 文件夹。Windows 还需安装 [Microsoft Visual C++ v14 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。当前尚未完成干净机器上的便携包验证。

## 数据与隐私

截图、OCR 和本地模式的系统音频推理都在本机处理，当前识别结果在停止时清空。选择云端实时翻译并开始后，所选播放设备的混合声音会上传至百炼北京；麦克风关闭，截图不上传。字幕记录保留在本次运行的有界内存中，退出或主动清空时移除。下载模型会连接 ModelScope 或 Hugging Face，但不发送截图、音频或识别文本；已调用推理运行时的遥测关闭接口。模型来源、哈希与许可证见 [模型说明](MODEL_NOTICES.md)。

屏幕或本地音频识别后开启文本翻译，识别文字会发送到配置的服务；请求包含当前段落和翻译提示，不包含截图或录音。云端实时语音会发送音频并直接返回原译文，不再另外调用文本翻译接口。在线服务可按其政策处理或保留上传内容，并非完全离线。当前译文和去重缓存停止后清空，字幕记录按上述规则保留；主动复制或导出后，剪贴板或文件中的文本由用户管理。

服务地址、模型和语言配置保存在 `%LOCALAPPDATA%/EchoPane/translation.json`；API Key 单独保存在 Windows 凭据管理器的 `EchoPane.TranslationKey.v1` 项中，可在应用中删除。该保护依赖当前 Windows 用户环境，不能抵御拥有相同用户权限的恶意进程。音频仅在有界内存缓冲中处理，不写入录音文件。
