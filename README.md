# EchoPane · 随幕

让屏幕文字和正在播放的语音，变成可阅读的双语字幕。

EchoPane 是一款面向 PC 的实时翻译工具，目标是帮助理解外语视频、直播及其他屏幕内容。

> 项目处于早期开发阶段。当前已实现 Windows 屏幕捕获与实时预览，文字识别、语音字幕和翻译尚未接入，目前没有正式发行的安装包。

## 当前功能

- 选择显示器，捕获整块屏幕或框选区域。
- 在窗口中实时预览捕获画面。
- 移动、调整窗口大小，设置置顶与透明度。
- 开始、停止捕获；最小化到托盘后继续运行。
- 通过托盘恢复窗口、停止捕获或退出。
- 从捕获画面中排除应用自身窗口，避免重复捕获。

当前捕获画面只在本机内存中处理，不上传或自动保存截图。

## 计划功能

- **屏幕翻译**：本地识别捕获区域中的文字，翻译为选定语言。
- **语音字幕**：转写系统正在播放的语音，并提供翻译。
- **双语对照**：在悬浮窗中展示原文与译文，无需语音播报。
- **语言设置**：自动判断源语言，也支持手动指定；首批重点验证英语、日语到简体中文。
- **会话记录**：回看当前会话中的字幕，支持主动复制或导出。

首版计划通过模式切换使用屏幕翻译或语音字幕；后续支持两种模式同时运行，并按来源分别展示。

## 平台

当前开发与验证平台为 **Windows 11 x64**。macOS 和 Linux 桌面端作为后续扩展方向，移动端纳入长期规划。

## 从源码运行

需要 Flutter 3.47.6（Dart 3.13.5）及 Visual Studio 的“使用 C++ 的桌面开发”工具和 Windows SDK 10.0.26100 或更新版本。Windows 需开启开发者模式，以支持 Flutter 插件的符号链接。

```powershell
flutter pub get
flutter run -d windows
```

构建 Windows 版本：

```powershell
flutter build windows --release
```

输出位于 `build/windows/x64/runner/Release/`。运行 `echopane.exe` 时，需要保留同目录下的 DLL 和 `data/` 文件夹。

## 数据与隐私

识别与翻译接入后，默认方案是在本机识别截图和音频，仅将识别后的文字发送给用户选择的翻译服务。在线翻译时，文本仍会传输到该服务。

计划由用户在图形界面配置自己的翻译服务 API Key。字幕历史默认仅保留在当前会话中，用户可以主动导出。
