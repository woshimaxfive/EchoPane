# EchoPane · 随幕

让屏幕文字和正在播放的语音，变成可阅读的双语字幕。

EchoPane 是一款面向 PC 的实时翻译工具，目标是帮助理解外语视频、直播及其他屏幕内容。

> 项目处于早期开发阶段。当前已实现 Windows 屏幕捕获、本地文字识别、翻译接口接入与双语展示。翻译链路已通过本地模拟接口测试，真实服务质量与延迟尚待验证；语音字幕尚未接入，目前没有正式发行的安装包。

## 当前功能

- 选择显示器，捕获整块屏幕或框选区域。
- 在窗口中实时预览捕获画面。
- 移动、调整窗口大小，设置置顶与透明度。
- 开始、停止捕获；最小化到托盘后继续运行。
- 通过托盘恢复窗口、停止捕获或退出。
- 从捕获画面中排除应用自身窗口，避免重复捕获。
- 在本机识别画面中的文字，并显示、选择和复制原文。
- 下载、校验并缓存约 21.5 MB 的 OCR 模型，缓存完整后可离线识别。
- 完全相同的画面跳过重复识别；后台仅保留最新待识别画面。
- 配置 DeepSeek 官方预设或自定义 Chat Completions 兼容服务，选择源语言和目标语言。
- 原文与译文逐段对照，支持复制双语文本。
- 翻译失败时保留原文，提示手动重试；更新画面、停止或修改设置时丢弃过时译文。

当前捕获画面只在本机内存中处理，不上传或自动保存截图。

## 使用屏幕识别

1. 首次运行点击 **下载模型**，等待本地模型就绪。
2. 选择显示器，点击 **框选区域** 并拖出字幕或文字区域；按 Esc 取消框选。也可以选择 **整块屏幕**。
3. 点击 **开始**，识别结果会显示在“识别原文”中；复制按钮可复制当前原文。
4. 点击 **停止**，结束捕获并清空识别结果。

当前重点验证英语、日语的横排文字。字体、运动背景和字号会影响效果，整屏缩放后的小字尤其容易漏识别，建议先框选字幕区域。识别结果可能有错字，暂不支持语音转写。

## 使用翻译

1. 打开 **翻译服务**，选择 DeepSeek 官方预设，或填写自定义服务地址和模型名称。
2. 填写自己的 API Key，选择源语言与目标语言后保存。Key 保存在当前用户的 Windows 凭据管理器中；普通配置文件不包含 Key。更换服务主机时，旧 Key 不会自动带到新服务。
3. 开始屏幕识别后，手动开启 **翻译**。译文会显示在对应原文下方。没有 Key 时，可以只使用本地原文识别；本机无鉴权模型服务允许留空 Key。
4. 翻译失败时检查地址、模型、Key 或余额，再点击 **重试翻译**。重启应用后翻译默认关闭。

自定义地址可以填写基础地址（例如 `https://example.com/v1`），也可以填写完整 `/chat/completions` 地址。远程服务必须使用 HTTPS；HTTP 仅允许本机回环地址。高级设置可关闭服务不支持的 JSON 模式或思考参数。协议兼容性取决于具体服务，模型仍需按约定返回完整 JSON 段落；当前未逐一验证第三方服务。

DeepSeek 预设为 `https://api.deepseek.com`、`deepseek-flash`，关闭思考并请求 JSON 输出，依据 [官方接口文档](https://api-docs.deepseek.com/en/)。实际可用模型以服务方为准。在线调用可能产生费用；应用不会在失败后自动重试。“测试连接”只发送一句固定测试文本，也可能产生服务费用。

## 计划功能

- **字幕稳定**：改善动态背景、小字和识别抖动，验证真实视频的翻译质量与延迟。
- **语音字幕**：转写系统正在播放的语音，并提供翻译。
- **语言扩展**：按 OCR 模型和翻译服务能力验证更多语言；语言设置列表不代表对应 OCR 语言均已验证。
- **会话记录**：回看当前会话中的字幕，支持主动复制或导出。

首版计划通过模式切换使用屏幕翻译或语音字幕；后续支持两种模式同时运行，并按来源分别展示。

## 平台

当前开发与验证平台为 **Windows 11 x64**。macOS 和 Linux 桌面端作为后续扩展方向，移动端纳入长期规划。

## 从源码运行

需要 Flutter 3.47.6（Dart 3.13.5）及 Visual Studio 的“使用 C++ 的桌面开发”工具和 Windows SDK 10.0.26100 或更新版本。Windows 需开启开发者模式，以支持 Flutter 插件的符号链接。

首次 Windows 构建会下载并校验官方 ONNX Runtime 1.30.0 与 OpenCV 4.13.0 开发包，下载量约 277 MB。默认缓存在构建目录的 `ocr-deps/` 中；可通过环境变量 `ECHOPANE_OCR_DEPS` 指定持久缓存目录。构建依赖与应用内下载的 OCR 模型相互独立。

```powershell
flutter pub get
flutter run -d windows
```

构建 Windows 版本：

```powershell
flutter build windows --release
```

输出位于 `build/windows/x64/runner/Release/`。运行 `echopane.exe` 时，需要保留同目录下的 DLL、`data/` 和 `licenses/` 文件夹。Windows 还需安装 [Microsoft Visual C++ v14 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。当前尚未完成干净机器上的便携包验证。

## 数据与隐私

当前截图和 OCR 推理都在本机处理，原文仅保留在内存中，停止时清空。下载模型会连接 ModelScope，但不发送截图或识别文本；已调用推理运行时的遥测关闭接口。模型来源、哈希与许可证见 [模型说明](MODEL_NOTICES.md)。

开启翻译后，识别文字会发送到配置的服务；截图不上传。翻译服务可按其政策处理或保留文本，在线调用并非完全离线。请求仅包含当前段落和翻译提示，不包含屏幕图像或音频。原文、译文与去重缓存仅保留在内存中，停止后清空；当前没有字幕历史或导出功能。

服务地址、模型和语言配置保存在 `%LOCALAPPDATA%/EchoPane/translation.json`；API Key 单独保存在 Windows 凭据管理器的 `EchoPane.TranslationKey.v1` 项中，可在应用中删除。该保护依赖当前 Windows 用户环境，不能抵御拥有相同用户权限的恶意进程。后续音频识别也计划在本机处理。
